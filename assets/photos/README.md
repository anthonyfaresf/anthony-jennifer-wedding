# Couple Photos

## What goes here
- Real photos of Anthony + fiancée
- Format: `.jpg` or `.png` (`.heic` from iPhone gets converted on import)
- 5–10 photos minimum, 15–20 ideal for a generous gallery
- Mix of: tight portraits, landscape couple shots, candid moments, location shots

## How to add
- Drop directly into this folder
- Filename convention: `01-engagement-paris.jpg`, `02-portrait-tight.jpg`, `03-candid-laughing.jpg` (descriptive — helps me cue them in the right gallery slots)

## What I'll do with them
- Strip EXIF metadata (privacy + smaller file size)
- Convert to WebP + AVIF for performance
- Generate responsive sizes (480w / 768w / 1280w / 1920w)
- Build a lightbox gallery with keyboard nav + swipe support
- Optionally: pick a hero photo for the landing section

## Anti-pattern (do not do)
- AI-generated faces of you and your fiancée — real photos only per `CLAUDE.md` identity check
- Stock photos of "couples" pretending to be you — guests will know

## If you don't have photos yet
Flag it — I can stub the gallery with placeholders and we wire real ones in once a shoot happens.
